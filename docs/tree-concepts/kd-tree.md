# K-D 树 / 空间划分树（K-D Tree, Quadtree, Octree）

## 1. 定义

**K-D 树（k-dimensional tree）**是**组织 $k$ 维点集**的二叉搜索树：每层沿一个维度用**中位数切分**超平面，交替维度递归划分空间。

```
2-D 树（点集划分）                    对应二叉搜索结构（按 x/y 交替比较）
   y
   |   ·p4
   | ·p1   ·p2         p3 按 x 切 → 左子树点 x<p3.x …
   |  p3
   |    ·p5
   +----------------- x
```
- 构造：选维度（轮流 x,y,… 或按方差最大维）→ 找该维中位数点做根 → 递归左右；
- 存储：每节点一个点 + 切分维度；查询时用切分维判断走左/右子树。

## 2. 复杂度

| 操作 | 平均 | 最坏 | 说明 |
|---|---|---|---|
| 构建 | $O(n\log n)$ | $O(n\log n)$ | 每层排序/线性选择中位 |
| 最近邻（NN）查询 | $O(\log n)$（近似） | $O(n)$ | 需回溯兄弟子树（球裁剪剪枝） |
| 区间/范围查询 | $O(\sqrt n + \text{输出})$（2D） | $O(n)$ | 高维退化 |

- **维度灾难**：$k$ 大（>20）时几乎要访问全部点 → 高维应换近邻图/哈希（LSH）。
- 查询最坏 $O(n)$（病态点集），工程用"平衡划分 + 回溯上界剪枝"缓解。

## 3. 变体：空间划分树家族

| 结构 | 划分方式 | 适用 |
|---|---|---|
| **K-D 树** | 二分（一个点/维） | 点数据 NN/范围 |
| **四叉树（quadtree）** | 2D 方形四等分；**八叉树（octree）** = 3D 八等分 | 图像/体素/稀疏栅格 |
| **k-d-B 树 / R 树** | 空间对象用包围盒 | 磁盘/数据库空间索引，[r-tree.md](r-tree.md) |
| **VP 树 / 球树** | 按距离划分 | 度量空间 |
| **BSP 树** | 任意超平面剖分 | 图形学遮挡/场景管理 |

## 4. 核心操作思想

- **最近邻**：从根沿与查询点最近的子空间下探到叶 → 回溯：若"到兄弟子空间边界的距离 < 当前最近距"，则兄弟可能含更近点，进入检查；否则整棵兄弟剪掉 → 剪枝不等式是它高效的关键。
- **范围搜索**：矩形 $R$ 查询 = 沿切分维判断子树包围盒与 $R$ 相交否。
- 与 **BST** 的对照（[bst.md](bst.md)）：BST 在 1 维"键比较"，K-D 在 $k$ 维"交替切分超平面"——是**多维化的二叉搜索**。

## 5. 应用与教材

- **应用**：最近邻搜索、碰撞检测、点云/渲染（光子映射）、聚类、机器人路径规划；
- **教材**：计算几何（硕/博）、图形学入门（四叉/八叉空间索引）；
- 实现细节：中位数用 nth_element $O(n)$；叶子存桶减少回溯；维度选择策略影响性能。

## 6. 注意辨析

- K-D 树不是"平衡搜索树"对键有序性的推广：它不用于**精确等值查找**，而是空间近邻/范围；
- 高维注意退化与维度灾难；动态插入退化可用 **替罪羊式重建**（[scapegoat-tree.md](scapegoat-tree.md) 思想同样适用于 K-D）。
