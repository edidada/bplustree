# 树的同构（Tree Isomorphism）

## 1. 定义

两棵树 $T_1,T_2$ **同构（isomorphic）**，若存在顶点间的双射 $f:V_1\to V_2$ 保持**邻接关系**（$uv$ 是边 $\Leftrightarrow f(u)f(v)$ 是边）。直观：**忽略顶点标号/位置后形状相同**。

- **自由树（无根）同构**：上述定义，图同构在树上特例；
- **有根树同构**：额外要求把根映到根，并保持**父子关系**；有序树同构还要求**孩子顺序**逐一对应。

```
    a        e                a        e
   / \      / \             / \      / \
  b   c    f   g           b   c    g   f
    (自由树同构)               (自由树同构, 但作为【有序树】不同构)
```

## 2. 有根树同构判定：规范化字符串（AHU 算法的核心）

用**递归规范形**给每棵子树一个"签名"：
1. 叶：`()`；
2. 内部节点：把**所有子树的签名**排序后拼进括号 `(s1 s2 ... sk)`。

两棵有根树同构 $\Leftrightarrow$ 根的规范形相同（有序树则不排序直接拼）。比较可用字符串，或用**层编号压缩**（用映射把每层子树签名换成整数，避免 $O(n^2)$ 字符串比较）。

```
      a:  ( (()) (()) )      ← 两子树签名都是 (())
     / \
    b   c                    另一棵树根若也得 ( (()) (()) ) 则同构
   /     \
  x      y?   (叶: ())
```

## 3. 无根树（自由树）同构判定

去掉根的限制，两种标准思路：

1. **找根再套有根判定**：
   - 计算两棵树的**中心（center）**：若中心是单点 → 以该点为根；双中心 → 尝试两个根都做（或加一个虚根连双中心，比较其两子签名对）。
   - 中心 = 直径中点（偏心距最小，见 [tree-diameter.md](tree-diameter.md)）。
2. **AHU 算法**（Aho–Hopcroft–Ullman，1974）：
   - 每轮：删掉全部**当前叶**并给每棵"从叶上来的子树"分等级（对上一层节点按 (label, 邻居) 排序压缩）；
   - 重复直到 ≤2 节点；比较最后标签。

## 4. 复杂度

| 方法 | 时间 | 说明 |
|---|---|---|
| 规范串 + 排序 | $O(n\log n)$（或 $O(n)$ 若用基数/层级压缩技巧） | 实现直观 |
| AHU 层次删叶 | $O(n\log n)$ → 优化 $O(n)$ | 理论教材 |
| 哈希法 | $O(n)$ 期望 | 用子树哈希（如 $(a, h_l, h_r)$ 组合哈希）判定；碰撞风险需双哈希 |
| 图同构一般情况 | 未知多项式（GI 问题） | 树是**多项式可解**的特例（GI 目前类未知，树类已知 $O(n)$） |

## 5. 应用

- 化学信息学：**分子结构（分子图）比对**（同分异构体即同构判定）；
- 编译器：表达式/子树等价与常量折叠（[expression-tree.md](expression-tree.md) 的 DAG 合并）；
- 语法树去重、模式匹配（树模式 → 子树同构）、验证两棵 BST 是否"形状相同"。

## 6. 教学层级

- **本科/竞赛**：序列化比较（`(子树)` 括号串）；
- **硕士算法（AHU）**：AHU 算法是"图同构特例可解"的经典案例，出现在算法导论习题与组合搜索教材；
- **研究**：GI 一般性与树宽参数化算法、子树同构（模式树匹配）。

## 7. 易错点

- 有序 vs 无序：排序 vs 不排序；
- 无根 vs 有根：先定根（center 或任取同构下不变的点）；
- 用最小表示：括号串内部要排序到规范序，否则同一树的多 DFS 序会判错。
