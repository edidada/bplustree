# 树的存储表示（Representation of Trees）

> 覆盖三种经典表示 + 工程级扩展。以 一棵一般树 为例贯穿全文：

```
        (a)
       / | \
    (b)(c)(d)
    /     / \
  (e)(f) (g)(h)
```

## 1. 双亲表示法（parent array）

用一维数组存节点，每项记录 `data` 与 `parent 下标`（根的 parent = −1）。

| 下标 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| data | a | b | c | d | e | f | g | h |
| parent | −1 | 0 | 0 | 0 | 1 | 1 | 3 | 3 |

- 优点：**找父 $O(1)$**、空间 $n$、易于判断根/叶的祖先关系。
- 缺点：**找子需遍历**。
- 使用场景：并查集（[union-find.md](union-find.md)）的 `fa[]` 数组即此表示；B+ 树 `.boot` 中"根节点偏移 + 树信息"的思想类似"元数据 + 指针"。

## 2. 孩子表示法（children lists）

每个节点指向一个"孩子链表"，常见三种：

1. **孩子链 + 顺序存储数组**：每个节点带子链头；经典实现（严蔚敏的"孩子链表"）另加 parent 字段。
2. **动态链表（邻接表）**：每个节点一个动态数组 `children`，是工程/图论最常用表示（DFS 树、目录树）。
3. **邻接表（图论语境）**：存"所有邻居"，再用根把方向标出——见 [graph-tree.md](graph-tree.md)。

优点：**遍历子树/孩子方便**；缺点：找父可能需遍历或另存 parent。

## 3. 孩子兄弟表示法（left-child right-sibling）★ 重点

用 **二叉树节点** 表示一般树：每节点只有两个指针——`first_child`（左孩子指针）与 `next_sibling`（右兄弟指针）。即 [ordered-tree.md](ordered-tree.md) 的"左孩子右兄弟（LCRS）表示"。

```
(a)                     (a)
/ | \      LCRS       /
(b)(c)(d)            (b)
/    / \     →        \
(e)(f)(g)(h)          (c)  ← a 的下一个兄弟位置
                      /
                    (d)
```
具体对上面例子展开即每个节点的"右指针"串起它的兄弟们：
```
a → first_child=b ; b → first_child=e, next_sibling=c ; ...
```

- **优点**：任意树/森林都能用 **二叉树** 的存储/算法统一处理（栈模拟、线索化），结构同 [binary-tree.md](binary-tree.md)。
- **转换规则（必考）**：
  - 树 ↔ LCRS 二叉树可互转且**结构同构**；
  - 树的**先序**遍历 $=$ LCRS 二叉树的**先序**；
  - 树的**后序**遍历 $=$ LCRS 二叉树的**中序**（务必记牢，最易错）。
  - 森林加虚根后同法转换；转回时根无右子为树、有右子为森林。

## 4. 顺序化 / 括号表示

- **广义表表示**：`(a (b (e,f), c, d (g,h)))`——树（尤其表达式树）的文本序列化。
- **DFS 括号序/欧拉序**：进入记 $(v)$、离开记 $)$，祖先-后代关系即"括号嵌套"；这是树上区间问题（LCA、子树区间查询）的基础，见 [lca.md](lca.md) 与 [segment-tree.md](segment-tree.md)。
- **先序序列 + 每节点度**（如 `(a,3)(b,2)...`）能唯一还原一般树。

## 5. 存储表示选择指南

| 需求 | 推荐 |
|---|---|
| 只需查父/并查集 | 双亲数组 |
| 遍历子树为主 | 孩子链（动态数组） |
| 想把一般树套进二叉算法/线程化 | LCRS |
| 树作为图、需要双向 | 邻接表 + parent 标记 |
| 磁盘/序列化 | 括号序/带度先序；数据库用页内偏移指针（B 树） |

> 工程补充：B+ 树节点在磁盘上以**块内偏移数组**表示孩子与兄弟，本质是"数组 + 指针/偏移"的混合表示，见 [b-tree.md](b-tree.md) / [bplus-tree.md](bplus-tree.md)。
