# 有序树 / 无序树（Ordered / Unordered Tree）

## 1. 定义

树是一种**离散结构**，但当我们记录"父→子"关系时，孩子的**集合**是无序的。两种约定：

- **无序树（unordered tree）**：节点的孩子之间没有先后之分，任意交换两棵子树得到的树被认为是**同一棵**。
- **有序树（ordered tree）**：节点的孩子排成一个**有顺序的序列**（第 1 子、第 2 子、……），交换孩子顺序得到**不同**的树。

```
  无序树：  (a)         (a)        视为同一棵
           /   \   =   /   \
         (b)  (c)    (c)  (b)

  有序树：  (a)         (a)        视为不同（第1子不同）
           /   \   ≠   /   \
         (b)  (c)    (c)  (b)
```

> 现实例子：文件系统目录是无序树（ls 顺序只是展示）；家谱是有序概念较弱；而**二叉树天生是有序的**（左/右孩子含义不同）。

## 2. 为什么有序性重要

1. **二叉树是"有序树 + 最多两个孩子"的特例**，且即使只有一个孩子也要区分是左还是右：
   ```
       (a)          (a)         二叉树中 ≠
      /               \
    (b)              (b)
   ```
   这带来存储差异（空链域的位置不同，见 [threaded-tree.md](threaded-tree.md)）。

2. **遍历结果区分结构**：同一组节点排成的无序树只有一种"先序结构"，而有序树的先序结果可区分不同形态。用两棵子树能否互换来判别"是否有序树"。

3. **计数不同**：
   - $n$ 个节点的**无序根树**数目与 **有序（平面）根树** 数目不同；
   - $n$ 个节点的**有序二叉树**恰有 **Catalan 数** $C_n=\frac{1}{n+1}\binom{2n}{n}$ 种；
   - 对应地，$n$ 个节点的（有序）**根树**（孩子可多个但有序）数目也由 Catalan 数刻画，因为**有序根树与二叉树之间存在双射**（见下）。

## 3. 树/森林/二叉树互转（有序化工具）

**左孩子右兄弟表示法（二叉树化）** 让有序树 ↔ 二叉树一一对应：
- 每个节点的"第一个孩子"记为二叉树的左孩子；
- "下一个兄弟"记为二叉树的右孩子。

```
原有序树          二叉树（left-child right-sibling）
     a                    a
   / | \                /
  b  c  d              b
       |               \
       e                c
                        \
                         d
                        /
                       e
```
结论（本科必考）：
1. 任何**有序树/森林**都能唯一转换成二叉树，反之不唯一（加回"右孩子是兄弟"信息）；
2. 转换后的二叉树**右子树一定为空**当且仅当原树没有根兄弟（即它是树而非森林）；
3. 树先序遍历 = 对应二叉树的先序遍历；树后序遍历 = 对应二叉树的**中序**遍历（经典易错点，见 [traversal.md](traversal.md)）。

## 4. 位置树（positional tree，硕士术语）

一般化概念：**位置树**中，若一个节点有 $d$ 个孩子，则这些孩子占据固定的"位置 1..d"，位置 $i$ 的孩子**可以缺失**（但缺失位置仍占位，使同层兄弟的"第几子"信息不因缺口而前移）。
- 二叉树是"至多 2 个位置"的位置树；
- B 树/多路搜索树（[b-tree.md](b-tree.md)）是"至多 $m$ 个位置"的搜索树——孩子位置 $1..m$ 与键的位置交错定义。

## 5. 各层级视角

- **本科**：会做"树↔二叉树转换"题，能说出有序与无序在旋转对称、交换上的区别。
- **硕士**：有序树与二叉树的**双射**是推导 Catalan 计数、动态规划（如括号序列、出栈序列）统一解法的基础；平面树（plane tree）在有向无环图枚举中出现。
- **博士/组合视角**：有序树计数 $\to$ 生成函数 $T(z)=\frac{1-\sqrt{1-4z}}{2z}$，与 [prufer-sequence.md](prufer-sequence.md)（无序树计数）形成对照：无序树由 Cayley 公式 $n^{n-2}$ 计数，有序树由 Catalan 计数。
