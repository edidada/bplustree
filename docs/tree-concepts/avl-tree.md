# AVL 树（Adelson-Velsky & Landis，高度平衡树）

## 1. 定义

**AVL 树**是满足**高度平衡**的二叉搜索树（BST，见 [bst.md](bst.md)）：对任意节点 $v$，

$$ |\,h(v\text{.left}) - h(v\text{.right})\,| \le 1 $$

其中 $h$ 按本库约定（空树 −1、叶 0，[height.md](height.md)）。左右子树高度差称 **平衡因子（balance factor）**，取值只能是 −1/0/+1：

$$\mathrm{bf}(v) = h(\text{左}) - h(\text{右}) \in \{-1,0,+1\}$$

## 2. 为什么叫"平衡"：高度上界

含 $n$ 个节点的 AVL 树高度 $h$ 满足

$$ h \le 1.44\log_2(n+2) - 1.33 \quad\Rightarrow\quad h = O(\log n) $$

证明思路：设 $N_h$ = 高度恰为 $h$ 的 AVL 树**最少**节点数，则 $N_h = N_{h-1} + N_{h-2} + 1$（左右各取最不平衡），$N_0=1, N_1=2$——类似 **Fibonacci**，得 $N_h\ge \varphi^h$。这保证查找、插入、删除均 $O(\log n)$。

## 3. 旋转（rotation）：平衡的修复原语

AVL 的一切维护 = 四种旋转（以平衡因子超界点为"失衡点" $v$）：

| 情形 | 形状 | 操作 | 效果 |
|---|---|---|---|
| LL | $v$ 的左子之左长出 | **右旋（单旋）** | 左子上提 |
| RR | $v$ 的右子之右长出 | **左旋** | 右子上提 |
| LR | $v$ 的左子之**右**长出 | **先左旋（左子）再右旋**（双旋） | 孙子变子树根 |
| RL | $v$ 的右子之**左**长出 | **先右旋再左旋** | 同上 |

LL 右旋示例（失衡点 $v=(3)$，其左子树太高）：
```
        (3)                     (2)
       /   \                   /   \
     (2)   (4)   右旋 →      (1)   (3)
    /                               \
  (1)                               (4)
```
RR 左旋与上镜像对称（右子右倾则左旋上提右子）；LR/RL 双旋 = 先在低层旋转一次变为 LL/RR 形态，再按对应单旋处理。
- **旋转保持 BST 性质**（中序不变），只改变层高分布；
- 单旋 $O(1)$ 指针调整；双旋 = 两次单旋，$O(1)$。

## 4. 插入与删除的平衡维护（本科必考细节）

**插入**：新叶可能使某祖先 $\mathrm{bf}$ 变 ±2。
- 只需**沿插入路径回溯**，找到**最近的失衡点**，做一次单旋或双旋即可**全局恢复**——因为旋转使该子树高度复原为失衡前，上层不再受影响；
- 结论：插入至多一次重构（单/双旋）。

**删除**：删除节点可能让**多个**祖先失衡，需要**沿路径一直向上检查并旋转**；
- 每次旋转使子树高度可能减 1，可能继续引起上层失衡 → 最坏 $O(\log n)$ 次旋转；
- 复杂度：删除仍 $O(\log n)$，但常数更大、实现更繁。

## 5. 实现要点与优化

- 每个节点存平衡因子或高度字段（删除时需知道"到底减了没有"，高度更易维护，一般存 `height`）；
- 失衡判定与旋转对称情形成对处理（LL 与 RR、LR 与 RL 镜像）；
- 旋转后要**逐层重算高度/bf**（自下而上）。

## 6. 教学/历史位置

- 1962 年提出，第一个自平衡 BST；"平衡因子 ±1"为后续所有平衡树的模板。
- **对比**（[red-black-tree.md](red-black-tree.md)）：
  - AVL 更严格 → 查找略快；红黑树放松"严格高度"换取**删除/插入的旋转次数更少**（AVL 删除最坏 $O(\log n)$ 旋转，红黑 ≤ 3 次旋转）；
  - 查多改少的场景 AVL 占优，插入删除频繁（如内核 rbtree、Java TreeMap）红黑更合适。
- 更一般化：平衡因子允许多大仍能保证 $O(\log n)$？→ 重量平衡/高度平衡的推广见 [scapegoat-tree.md](scapegoat-tree.md)。
