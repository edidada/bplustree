# 后缀树（Suffix Tree）

## 1. 定义

给定字符串 $S$（设 $|S|=n$，结尾加特殊哨兵符 `$` 保证每个后缀止于叶），**后缀树**是 $S$ 的**全部后缀**构成的**压缩字典树（compressed trie）**，见 [trie.md](trie.md)：

- 每条边带一个**非空子串标签**（存储为 `[start,end)` 区间引用原串，O(1) 空间）；
- 从根到叶的标签拼接 = 一个后缀；
- $n+1$ 个叶（含空后缀）；内部节点恰有 ≥2 个子 → **内部节点数 ≤ n−1**，总节点 $O(n)$。

```
S = "banana$"  后缀: banana$ anana$ nana$ ana$ na$ a$ $
（示意）      root
            /  |  \
          ba  na  a  ...（压缩了单链）
          |   | \
        nana$ na$ ...
```
关键性质：**任一子串 = 某两个叶后缀的公共前缀** → 从根沿标签下探即可定位任意子串，而"从哪条边开始分叉"揭示重复。

## 2. 最伟大性质：线性时间的子串问题机器

后缀树能在 $O(n)$ 建好后，$O(\text{len}(p))$ 回答：

- 模式串出现（子串查询）、出现次数（子树叶数，配合区间统计思想 [segment-tree.md](segment-tree.md)）；
- **最长重复子串**（最深内点标签）、**最长公共子串**（两串建一棵树的 LCA/最深分叉）；
- 后缀树的 DFS = **字典序后缀排序**（关系后缀数组）；
- 在线性串算法课上，"**后缀树 = 后缀数组 + LCP 数组**的等价物"。

## 3. 构建算法（硕博必知名，不必背码）

| 算法 | 复杂度 | 要点 |
|---|---|---|
| 朴素插入全部后缀 | $O(n^2)$ | 教学定义用 |
| **Ukkonen（1995）** | $O(n)$ | **在线**、每次延长"当前后缀"；核心技巧：后缀链接 + 活动点/剩余后缀数 + 边区间延展，避免重扫 |
| **McCreight（1976）** | $O(n)$ | 离线 |
| 后缀自动机（SAM） | $O(n)$ | 最小 DFA，兄弟结构 |
| 后缀数组 + LCP | $O(n)$ (DC3/SA-IS) | 工程更省内存的实现路线 |

## 4. 变体与替代（工程实话）

| 结构 | 关系 |
|---|---|
| 后缀数组（SA） | 后缀字典序数组，可配 LCP 模拟后缀树；**省内存**（$\sim4n$ 字节 vs 后缀树 $20n$+） |
| 后缀自动机（SAM） | 收**所有子串**的最小 DFA；在线、可增量 |
| 广义后缀树 | 多串共树（用分隔符） |
| 压缩关系 | 后缀树=压缩后缀 trie；省去压缩即 $O(n^2)$ 节点的朴素后缀 trie |

## 5. 应用领域（博士/工程）

- 基因组学：最长公共子串、reads 比对、重复序列查找；
- 数据压缩：重复检测（LZ 系）；
- 信息检索：全文索引的经典方案（如今多以后缀数组/倒排表实现）；
- 生物信息学教材（Gusfield, *Algorithms on Strings, Trees and Sequences*）是权威参考——书题即含 "Trees"。

## 6. 复杂度速记

- 节点 $O(n)$、构建 $O(n)$、单次子串查询 $O(|p|)$、统计出现次数 $O(1)$（预存叶数）。
