# 树的重心（Centroid of a Tree）

## 1. 定义

**重心（centroid）** 是一个（或两个）顶点 $c$，满足：**删掉 $c$ 后，剩下的每个连通分量（子树）的大小都 $\le n/2$**。

等价地：$c$ 的所有子树的规模都 $\le n/2$（$n$=总节点数）。

```
        (c)         若 n=9，删 c 得三块：4、3、1（示意图）
      /  |  \       每块 ≤ 9/2=4.5 → c 是重心
    4   3   1
```
性质：
1. 重心**至多两个**，若有两个它们相邻，且删掉它们之间的边得到的两块都恰为 $n/2$；
2. 重心是"让**最大块最小**"的点（最小化删点后最大分量）；
3. 全树所有点到重心的距离和**最小**（无向树 1-median）；
4. **每个子树大小 > n/2 的路径只有一条**：从任一点沿"大小 > n/2 的方向"走即到重心——这给出 $O(n)$ 找法。

## 2. 与"中心（center）"严格区分（高频混淆）

| | 重心 centroid | 中心 center |
|---|---|---|
| 定义 | 删后最大块 ≤ n/2 | 偏心距最小的点（= 直径中点） |
| 依据 | **子树规模** | **到最远点距离** |
| 数量 | 1 或 2 | 1 或 2（直径中点） |
| 用途 | 分治/DP 平衡 | 半径/覆盖 |

见 [tree-diameter.md](tree-diameter.md) 中 center 的定义；两者名字都是"中心"，但一个是 size 平衡、一个是 distance 平衡。

## 3. 求法（一次 DFS）

```c
int find_centroid(v, p, n) {
    for (u in adj[v] if u != p)
        if (sz[u] > n/2) return find_centroid(u, v, n);   /* 唯一"大块"方向 */
    return v;
}
```
（子树大小需先算好：$sz[v]=1+\sum sz[\text{children}]$；注意还要考虑"父方向"的块大小 $n-sz[v]$。）

## 4. 应用：点分治（centroid decomposition）——树分治的基石

把重心删除后递归处理每个分量，得到**重心分解树**（每层规模减半 → 深度 $O(\log n)$）。用途：

- 树上"路径统计"（有多少条长度 ≤ K 的路径、点对距离统计）：每次以重心为"跨过重心"的路径计数，复杂度 $O(n\log n)$；
- 动态树分治（配数据结构维护）；
- 到重心距离和最小 → 选点/设施选址问题。

**为什么高效**：任何路径 $u$–$v$ 第一次"被某层重心分开"，总路径被每层恰好统计一次 → $O(\log n)$ 层 × 每层 $O(n)$ 处理。

## 5. 其它性质与应用

- 树上每个点删掉后的最大块 > n/2 的方向唯一（收敛引理）；
- 直径两端点到重心距离差的刻画（两点间距离不超过 $2\times$ 半径）；
- 竞赛常考：最小化"删点后最大连通块"（情报网络分割）、构造分治树。

## 6. 教学层级

- **本科/竞赛**：求重心、点分治入门；
- **硕士图算法**：与直径/中心/半径的区别题；
- **研究**：动态树分治、随机树的分布。
