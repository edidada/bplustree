# 森林与子树（Forest & Subtree）

## 1. 森林定义

**森林（forest）** = $m\ (m\ge 0)$ 棵**互不相交**的树的集合。

- $m=0$：空森林。
- 任取一棵树，删掉其根，剩下的就是由根的 $k$ 棵子树组成的森林；
- 反过来，给一个森林添加一个"虚根"（dummy root），把森林中每棵树的根作为虚根的子树，森林就变成一棵树：

```
  森林（两棵树）                    加上虚根成一棵树
    a      c                          (R)
   / \      \                        /   \
  b   d     e                      a     c
                                   / \     \
                                  b   d    e
```

> 递归定义的"树 = 根 + 若干子树"，子树集合本身即一个森林——**森林与树的递归相互定义**，这是所有分治树算法的结构基础。

## 2. 子树（subtree）

节点 $v$ 的 **子树** = 以 $v$ 为根、包含 $v$ 全部（严格）后代与它们之间边的**整棵**递归树。

关键性质：
1. **整体-局部**：子树的子树仍是子树；两个不同节点的子树要么不相交、要么一个完全包含另一个（树的"良基分解"性质，形成树上的偏序）。
2. **子树是算法分析的天然单位**：AVL 平衡因子、线段树区间统计、树 DP、树的同构（AHU）都定义在子树上。
3. **子树叶数/规模记号**：设 $s(v)$ 为 $v$ 子树大小（含 $v$），DFS 后序遍历可自底向上算出全部 $s(v)$。

## 3. 树 ↔ 森林 ↔ 二叉树 的互转（统一表）

| 转换 | 方法 | 用途 |
|---|---|---|
| 树 → 森林 | 删根 | 递归/分治 |
| 森林 → 树 | 加虚根 | 统一表示、便于转二叉树 |
| 树/森林 → 二叉树 | 左孩子右兄弟 | 存储、遍历统一（[ordered-tree.md](ordered-tree.md)） |
| 二叉树 → 树/森林 | 逆操作（根无右子=树；有右子=森林） | 还原 |

**判定要点**：二叉树还原成"树"要求根**没有右孩子**（否则根带兄弟，说明原是森林）。

## 4. 森林的存储与计数

- 存储上与树同构：任一"树表示法"把根数组化即可表示森林（[tree-representation.md](tree-representation.md)）。
- 并查集（[union-find.md](union-find.md)）维护的"等价类"就是一个**由若干树构成的森林**，其不变量"互不相交"正是森林定义。
- 组合计数：$n$ 个节点无序根树的计数（Cayley：$n^{n-2}$）在森林视角下等价于"选择各树根"的求和（参见 [prufer-sequence.md](prufer-sequence.md)）。

## 5. 递归结构带来的算法模板

绝大多数树算法都长这样：

```
solve(v):                    # 以后序为例
    for u in children(v):    # 递归处理每棵子树（= 森林中的每棵树）
        solve(u)
    combine(...)             # 汇总子树信息
```

例如：树高、子树大小、哈夫曼 WPL、B 树节点分裂对子树的搬运——无一例外。
