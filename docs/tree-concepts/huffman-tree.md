# 哈夫曼树 / 最优二叉树（Huffman Tree, Optimal Binary Tree）

## 1. 定义与背景

给定 $n$ 个带权叶节点（权 $w_i>0$），构造二叉树使 **带权路径长度 WPL 最小**：

$$ \mathrm{WPL} = \sum_{i=1}^{n} w_i \cdot \ell_i $$
其中 $\ell_i$ 为叶 $i$ 的**层次**（根为第 1 层，即路径上节点数）或路径长度。取节点计数还是边数只差常数，注意教材口径即可（本库按 [level.md](level.md)：叶到根路径长 = 深度，用边数/节点数都行，公式统一即可）。

满足 WPL 最小的二叉树称 **哈夫曼树 / 最优二叉树**。

```
叶权 a=7, b=5, c=2, d=4
          (18)
        /      \
     (a)7      (11)
              /    \
           (b)5    (6)
                  /   \
               (c)2  (d)4
WPL = 7*1 + 5*2 + 2*3 + 4*3 = 7+10+6+12 = 35（按深度）
```
权越大的叶应**离根越近**——哈夫曼算法的直观。

## 2. Huffman 构造算法（贪心）

1. 把每个权值作为单节点（叶），构成最小堆（[binary-heap.md](binary-heap.md)）；
2. 重复 $n-1$ 次：弹出**两个最小**的根，合并成新节点（权 = 二者之和，两树为左右子树），压回堆；
3. 剩最后一个根 = 哈夫曼树。

- 贪心正确性：**交换论证**（若有非最优局部选择可交换得到更优/等优解），证明略；结果不唯一（等权合并顺序不同）但 WPL 唯一最小。
- 复杂度：堆实现 $O(n\log n)$。
- 哈夫曼树**没有度为 1 的节点**：$n$ 个叶 ⟹ 总节点 $2n-1$（严格二叉树性质，[binary-tree-forms.md](binary-tree-forms.md)）。

## 3. 应用一：最优前缀编码（Huffman 编码）

把每个字符看作一个带权（= 出现频率）叶。编码规则：沿树从根到叶，左分支记 0、右分支记 1，叶的路径即该字符的码字。

- 所有字符都落在**叶**上 → 任意码字都不是另一码字前缀 → **前缀码（无歧义解码）**；
- WPL 最小 = 平均码长最短 → 无损压缩（ZIP/JPEG 等的熵编码基石之一）；
- 编码树是**字典树**（[trie.md](trie.md)）的特例：叶子即词典终点，无内部叶。

## 4. 变体与延伸（研/博士视角）

- **$k$ 叉哈夫曼**：每次合并 $k$ 个最小权（注意要补权 0 的虚叶使 $(n-1)\bmod(k-1)=0$）；
- **哈夫曼 + 概率分布**：WPL 最小 ↔ 码长接近 $- \log_2 p_i$（Shannon）；与熵的差距 = 冗余；
- **次优/受限树**：长度受限哈夫曼（RFC 1951 deflate 用受限码长）；
- **与败者树无关**：哈夫曼挑最小的两个（堆），归并用胜者/败者树（[tournament-tree.md](tournament-tree.md)）——别混。
- **算法家族**：最优合并问题（merge patterns）与哈夫曼同构：将 $n$ 个长度文件两两合并的最少代价就是哈夫曼树 WPL。

## 5. 考点

- 手工构造哈夫曼树并求 WPL（贪心步骤）；
- 给定字符频度求平均码长；
- 判断：某个前缀码表是否为"哈夫曼编码"（必要不充分：等长编码也可以是某些分布的哈夫曼码）。
- 扩展二叉树视角：外部节点 = 编码字符。
