# 笛卡尔树（Cartesian Tree）

## 1. 定义

**笛卡尔树**是以一个**二元组序列** $(k_i, w_i)$ 构造的二叉树：

- **按键 $k$**：满足**中序遍历 = 序列顺序**（若键即下标/排序序则中序固定为输入序）；
- **按权 $w$**：满足**堆序**（$w_{\text{父}} \le w_{\text{子}}$，最小堆版）。

```
序列（键=下标 1..7，权 w = [9,3,7,1,8,12,10]），最小堆版：

            (4,1)              ← 全局最小权 1 → 根
          /      \
      (2,3)      (5,8)         ← 左半最小 3、右半最小 8
     /     \         \
  (1,9)   (3,7)     (7,10)     ← (7) 权 10 比 (6) 权 12 小
                    /
                (6,12)         ← 6 是 7 的左子树
```
验证：**中序 = 1 2 3 4 5 6 7**（键序）；**堆序** 沿每条根叶路径权递增（1≤3≤9、1≤3≤7、1≤8≤10≤12）。权相同时需约定严格序（如比下标），保证唯一。

**性质**：键 + 堆序两者同时满足时，给定二元组序列的笛卡尔树**存在且唯一**（Treap 就是"随机权 + BST 键"的笛卡尔树，[treap.md](treap.md)）。

## 2. 线性构造算法（单调栈）

对序列从左到右扫描，维护"右链"单调栈：

- 新元素 $x$ 的权若小于右链顶，弹出栈顶直到找到权更小者 $p$：**被弹出的最后一个是 $x$ 的左子**，$x$ 成为 $p$ 的右子（维持中序 = 输入序）。
- 每个元素入/出栈一次 → **$O(n)$ 构造**（这是它最重要的算法价值）。

```c
/* 最小堆笛卡尔树：left/right 为节点在输入序列中的下标；0 空 */
for (i = 1; i <= n; i++) {
    int last = 0;
    while (top && w[st[top]] > w[i]) last = st[top--];   /* 比 i 大者弹出 */
    if (top) right[st[top]] = i;                         /* i 挂到栈顶右侧 */
    left[i] = last;                                      /* 最后弹出的做 i 左子 */
    st[++top] = i;
}
```

## 3. 关键性质（作用在数组/区间题上）

1. **RMQ 的钥匙**：$w$ 上的区间最小值查询 = 两下标在笛卡尔树上的 **LCA**（[lca.md](lca.md)）。因为最小堆根是整个区间最小，LCA 即区间最小元素：
   - "区间 $[l,r]$ 的最小值" → `LCA(笛卡尔树, l, r)`；
   - 这给了 RMQ 与 LCA 的**互相转化**（$O(n)$ 建树 + 稀疏表/$O(1)$ LCA）。
2. **最大矩形/直方图**：经典题"直方图最大矩形"的本质：以最小值为根、左右子问题递归，面积 = 高 × 宽；单调栈解法正是构造笛卡尔树的过程。
3. **子数组最小/最大贡献类题**（如"每个子数组最小值之和"）：以 $w_i$ 为最小值的区间 = 笛卡尔树中 $i$ 子树对应的下标范围。

## 4. 与 treap、二叉树序列的唯一性

- Treap = 随机权笛卡尔树（BST 视角）→ 随机权给出随机 BST 的等价结构（[treap.md](treap.md)）；
- 笛卡尔树告诉我们：**任一"数组 + 优先级"组合都唯一对应一棵树**，这一"唯一性+可在线构造"在可持久化 treap、后缀树建树（Ukkonen 的右链技巧与其同构）里反复出现；
- 后缀数组+LCP 的 **Cartesian 化**也用于 O(1) LCP。

## 5. 教学层级

- **本科/竞赛提高**：单调栈解法"原来是建笛卡尔树"，直方图最大矩形、RMQ 转 LCA；
- **硕士算法课**：唯一性证明、$O(n)$ 构造、与 treap/随机 BST 的关系；
- **博士/字符串**：后缀树的线性构建与笛卡尔树"右链展开"技术同源。
