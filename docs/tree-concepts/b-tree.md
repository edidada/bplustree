# B 树（B-Tree，多路平衡搜索树 / 磁盘索引树）

## 1. 动机：内存树 vs 磁盘树

二叉树每个节点 1 键 2 子：高度 $O(\log_2 n)$。若把"一次节点访问"换成"一次**磁盘 I/O**"，$\log_2 n$ 次 I/O 太贵（随机 I/O ~ms 级）。**B 树思想：一节点塞进一个磁盘页/块**（如 4KB 可存数百键），把高度压到 $O(\log_m n)$——树越矮，根到叶的 I/O 越少。本仓库 `lib/bplustree.c` 即以 4096B block 为节点、单文件实现此结构。

## 2. 定义（order / 最小度数两套记法，必分清）

**记法 A（阶 m / order）**—— 国内教材主流：
- 每个节点至多 $m$ 个孩子、至多 $m-1$ 个键；
- 非根内部节点至少 $\lceil m/2\rceil$ 个孩子（键至少 $\lceil m/2\rceil-1$）；
- 根例外（至少 2 子，除非是叶）；
- 所有叶同一深度。$m=3$ 即 2-3 树，$m=4$ 即 2-3-4 树（[23-tree.md](23-tree.md)）。

**记法 B（最小度数 $t$）**—— CLRS 系：
- 每个节点至多 $2t-1$ 个键、$2t$ 个孩子；至少 $t-1$ 键（根除外）。两记法等价于 $m=2t$。

> 别把 $t$ 当"度（degree）"看：它是节点键数下界参数，与 [degree.md](degree.md) 中"节点孩子数"的度**同名不同义**。

**本仓库注意**：`lib/bplustree.c` 读配置时打印 `node order:338 and leaf entries:338`，指其每个 block 能容纳的键/子偏移数组数量由块大小推导，即这里的 $m$ 由**页大小**决定。

## 3. 查找

从根开始：节点内二分找键（命中即返回）；否则按区间进入对应孩子；到叶仍未命中即不存在。$O(\log_m n)$ 次 I/O + 节点内 $O(\log m)$ 二分。

## 4. 插入：先满则分裂，自底向上长高

规则：插入总是落到叶。若叶已满（$m-1$ 键），**分裂**：
1. 把 $m$ 个键的中间键上提给父，左右两半各自成节点；
2. 父若因此满 → 递归分裂；根满 → 根分裂，树高 +1（全局唯一增高的方式）。

```
order 5（每节点 ≤4 键），叶满 [1 2 3 4]，插入 5
   → 分裂：3 上提，得 [1 2] [3] [4 5]
```
预分裂优化：自顶向下插入路径上遇到满节点**先分裂**，可避免回溯（Knuth/CLRS 建议写搜索+一次向下完成）。

## 5. 删除：欠则借/并，必要时合并

删除内部键：用**前驱/后继（最邻近叶键）上移替换**，转化为删叶键（同 BST 删除技巧，[bst.md](bst.md)）。删叶键后若键数低于下限 $\lceil m/2\rceil-1$：

- **借（rotation）**：相邻兄弟键数富余 → 父键下移、兄弟键上移；
- **并（merge）**：兄弟也到下限 → 父的一个键拉下与两兄弟合并，父键数 -1；父再欠 → 逐层上溯；根被并空则根删除、树高 -1。
- 预合并优化：向下删除路径遇"可并"节点先并，避免回溯。

## 6. 复杂度总表

| 操作 | I/O（磁盘访问） | CPU |
|---|---|---|
| 查找 | $O(\log_m n)$ | $O(\log_m n\cdot \log m)$ |
| 插入/删除 | $O(\log_m n)$（分裂/合并链） | 同上 + 节点内移动 $O(m)$ |
| 高度 | $h = O(\log_m n)$ | 例：$m=338$（本仓库配置），$10^6$ 键高 ≈ 2–3 |

**实际工程界**：$n=10^9,\ m=1000$ 时 $h\approx 3$ → 三次 I/O 内查任意键，这是数据库索引的立身之本。

## 7. 变体与位置

| 变体 | 区别 | 文件 |
|---|---|---|
| B+ 树 | 数据只在叶；叶链支持范围扫描；内部只存键 | [bplus-tree.md](bplus-tree.md) |
| B* 树 | 分裂要求 2/3 满才允许、分裂时先与兄弟重分配 | — |
| 前缀压缩/哈夫曼码 | 降低内部键存储 | 博士话题 |
| 红黑树 | = order-4 的二叉化（内存版） | [red-black-tree.md](red-black-tree.md) |

- **历史**：Bayer & McCreight 1972 提出；名字"B"解释众说（Boeing/balanced/Bayer），学术上就用字母 B。
- **使用**：文件系统（ext4 H-tree/B-tree、NTFS、Btrfs）、数据库（SQLite 页式 btree、InnoDB 的 B+ 聚簇索引）、键值库（LMDB）。
