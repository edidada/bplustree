# 树的定义（Tree）

## 1. 非形式化定义

一棵 **树** 是若干（零个或多个）**节点（node）**构成的有限集合，其中：

- 恰有一个节点称为 **根（root）**；
- 除根外，其余节点被分成 $m\ (m\ge 0)$ 个 **互不相交** 的非空集合 $T_1, T_2, \dots, T_m$，每一个集合本身又是一棵树，称为根的 **子树（subtree）**。

```
        (R)  ← 根
       / | \
      a  b  c        ← 三棵子树 T1={a,..}, T2={b,..}, T3={c,..}
     / \     \
    d   e    f        每个子集合本身也是一棵树（子树）
```

> 这一「**递归定义**」是整个树数据结构的基石：一切树算法（遍历、平衡、分裂、合并）几乎都建立在"子树仍是树"之上。

## 2. 形式化/递归定义（本科教材规范写法）

**定义（树）**：树是节点的有限集 $T$，满足：
1. $T=\varnothing$ 时称为 **空树**（empty tree），它也是树；
2. 否则 $T$ 中有且仅有一个特殊节点 $r$（根），且 $T-\{r\}$ 能划分为 $k\ge 0$ 个两两不相交的非空集合 $T_1,\dots,T_k$，每个 $T_i$ 都是一棵树，称它们为 $r$ 的子树。树中 $k=0$ 即根没有子树时该根同时也是 **叶**。

**定义（森林）**：$m\ge 0$ 棵互不相交的树的集合称为 **森林（forest）**。给森林加上一个虚根并把每棵树作为其子树，森林即变成一棵树；反之删去树的根，树变成森林（见 [forest.md](forest.md)）。

## 3. 图论定义：自由树（free tree）

在无向图论中，"树"不强调根，定义为：

> **树 = 连通且无环（无圈）的无向图**。见 [graph-tree.md](graph-tree.md)。

数据结构里的"根树/有根树"= 一棵自由树 + 指定一个根并给每条边定向（由根指向外）。两者关系：
- 自由树关心的是"边与顶点的结构"；根树额外关心"父→子"的层次关系，天然可用于表示递归分解与排序层次。
- 给自由树选不同根会得到不同的根树，但结构同构。

## 4. 树的六条等价性质（硕士/图论视角）

设 $G$ 是无向图，$n=|V|$，$m=|E|$，则以下命题**两两等价**，任一成立即 $G$ 是树：

1. $G$ 连通且无环；
2. $G$ 连通且 $m = n-1$；
3. $G$ 无环且 $m = n-1$；
4. $G$ 中任意两顶点之间有且仅有一条简单路径；
5. $G$ 连通，但删去任意一条边后不再连通（边极小连通）；
6. $G$ 无环，但添加任意一条新边恰产生一个环（边极大无环）。

> 用途：证明/反证树的性质时选择最顺手的一条。例如 B+ 树的叶链使结构上含"环"（叶间兄弟指针），此时谈的就不再是无向树而是"带额外链的树"——说明概念边界要先讲清楚（参见 [bplus-tree.md](bplus-tree.md) 对叶链的处理）。

## 6. 树的数学性质（常用引理）

- 一棵有 $n$ 个节点的树有 **$n-1$ 条边**。
- 从根到任意叶，不同叶之间**没有共享的后续路径分歧之外的边**（路径唯一）。
- 非空树的节点间深度关系：若 $v$ 是 $u$ 的子孙，则 $d(v)\ge d(u)$，且等号当且仅当 $v=u$ 或深度定义含自身。
- 任意树都可以用"递归=子树+根"分解，这给出树上的归纳证明框架（如证明叶数公式 $n_0 = n_2+1$ 用于二叉树）。

## 7. 教材视角小结

- **本科**：严蔚敏将树定义为"树是 $n(n\ge0)$ 个结点的有限集"，直接从空树开始；邓俊辉强调树是"半线性结构"（介于线性表与图之间），并给出"连通无环图 + 根"的严谨二段定义。
- **研究生/更高**：在算法课与图论中多用等价性质 2/4/6 把树当作"稀疏连通图"，关注 $m=n-1$ 带来的复杂度下界（如并查集、动态树的边数约束）。
