# 二项树与二项堆（Binomial Tree & Binomial Heap）

## 1. 二项树（Binomial Tree）$B_k$

按规则递归定义：
- $B_0$：单节点；
- $B_k$：由两棵 $B_{k-1}$ 连接而成（一棵的根作为另一棵根的最左孩子）。

```
B_0       B_1       B_2                B_3
•         •          •                 •
                    / \              / | \
                   •   •            •  •  •
                                      / \  ...
            2^0  2^1  2^2 = 4 节点    2^3 = 8 节点
```

**二项树的六个性质（本科/硕士常考）**：
1. $B_k$ 有 $2^k$ 个节点；
2. 高度 $=k$（根到最远叶）；
3. **根度为 $k$**，其子从左到右恰是 $B_{k-1},B_{k-2},\dots,B_0$；
4. 深度 $d$ 处恰有 $\binom{k}{d}$ 个节点（因此得名"二项"，与 $(1+x)^k$ 系数一致，见 [level.md](level.md) 的层计数）；
5. 总节点数 $2^k$（由性质 4 求和）；
6. 森林与合并的二进制类比基础。

## 2. 二项堆（Binomial Heap）

**二项堆** = **最小堆序的二项树森林**，且任意阶 $B_k$ **至多一棵**——即节点数 $n$ 的**二进制分解**：

```
n = 13 = 8+4+1  →  森林含 B_3, B_2, B_0
        B_3      B_2     B_0
        (…)      (…)     (•)
```
含 $n$ 个节点 ⇒ 至多 $\lfloor\log_2 n\rfloor+1$ 棵树、根度数 $O(\log n)$。

## 3. 操作：全部是"二进制加法"

| 操作 | 做法 | 复杂度 |
|---|---|---|
| merge | 同阶树两两合并（像二进制进位），从低阶到高阶 | $O(\log n)$ |
| insert | 单点堆 merge 进森林 | $O(\log n)$（摊还 $O(1)$：多数插入不进位） |
| find-min | 扫所有树根 | $O(\log n)$ |
| delete-min | 取最小根 → 把它的子树森林拆出 → merge 回原森林 | $O(\log n)$ |
| decrease-key | 修改后沿**父链**上滤交换 | $O(\log n)$ |

- 合并正确性即"二进制加法"：$13+7=20=16+4$ → $B_3,B_2,B_0$ 合并进 $B_2,B_1,B_0$ 逐位进位得 $B_4,B_2$。
- 摊还分析：势 = 树根数；insert 的摊还 $O(1)$（大多数时候无进位）。
- 优点：**merge 真 $O(\log n)$** 且实现比斐波那契简单得多。

## 4. 位置与对比

- **硕士教材（CLRS 第 19 章）**：二项堆是理解"合并堆 + 摊还"的阶梯，也是斐波那契堆的前身；
- **与二叉堆**：二叉堆 insert $O(\log n)$ 且无真 merge；二项堆用**树根数组**换来 merge 能力；
- **与斐波那契堆**：斐波那契堆 = 二项堆 + "懒惰合并 + 削标记"，把 decrease-key 与 merge 摊还降到 $O(1)$，见 [fibonacci-heap.md](fibonacci-heap.md)。

## 5. 教学要点

- 画图技能：会由二进制分解画森林、会演示两棵 $B_{k-1}$ 的合并；
- 会数：深度 $d$ 节点 $\binom{k}{d}$、$B_k$ 根度 $k$；
- 把二项堆 merge 想成"加法器"，delete-min 想成"拆根 + 加法"，几乎所有题都可秒解。
