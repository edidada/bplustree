# 层次 / 层数（Level）

## 1. 定义与起算

- **层次（level）**：把树按"离根多少条边"分行，从根开始逐层编号，根在第 **1** 层。
- 记 $\ell(v)$：根 $\ell=1$；若 $u=\mathrm{pa}(v)$，则 $\ell(v)=\ell(u)+1$。

```
        (a)         第 1 层（层数 = 1）
       /   \
     (b)   (c)      第 2 层
    /  \
  (d)  (e)          第 3 层
       第 i 层（若从上往下数）至多有 2^(i-1) 个节点（对二叉树）
```

## 2. 层数 vs 深度 vs 高度（最重要的对照表）

| 名称 | 起算点 | 方向 | 默认值 | 等价关系 |
|---|---|---|---|---|
| 层次 level | 根为第 1 层 | 从上往下 | $\ell(\mathrm{root})=1$ | $\ell(v)=\mathrm{depth}(v)+1$（当深度按边数计） |
| 深度 depth | 根为 0 或 1 | 从上往下（离根距离） | 见 [depth.md](depth.md) | 常写作 $\mathrm{depth}$ |
| 高度 height | 叶为 0 | 从下往上（离最远叶距离） | 见 [height.md](height.md) | $h(\mathrm{root})=$ 树的"最大层差" |

**通俗记忆**：
- 深度 = "从树顶往下数你掉了多少层（数边）"；层数 = "你在第几排"（数节点/从 1 开始）。
- 高度 = "从你最远的叶子往上数到你还要爬多少级"。
- 对一棵树，$\max_v \mathrm{depth}(v) = h(\mathrm{root}) = $ **树的高度 = 最大深度**（值相同），但**深度是单点的、高度也可是单点的**，二者概念方向不同。若采用"深度从 0、叶高 0"，则对任意 $v$：$\mathrm{depth}(v) + h(v) \le$ 树高，等号当且仅当 $v$ 在树的某条直径上（见 [tree-diameter.md](tree-diameter.md)）。

## 3. 满层与完全二叉树

- **第 $i$ 层的节点数上界**：一般树无上界（度可变）；**二叉树第 $i$ 层至多 $2^{i-1}$ 个节点**，故
  深度（从 0 计）$k$ 的二叉树至多含 $2^{k+1}-1$ 个节点。
- **完全二叉树（complete）** 的层序编号 $1..n$ 使：节点 $i$ 的父为 $\lfloor i/2\rfloor$、左子 $2i$、右子 $2i+1$ —— 这正是二叉堆用数组存树（[binary-heap.md](binary-heap.md)）与 B+ 树按层访问的编号基础。
- **"满层"**：若第 $i$ 层恰有 $2^{i-1}$ 个节点则称该层"满"。树的形态分类（perfect/complete/strict）就是围绕"哪些层满、最后一层怎么排"展开，详见 [binary-tree-forms.md](binary-tree-forms.md)。

## 4. 各教材起算差异（必须查清楚再读公式）

| 教材/习惯 | level 起算 | depth 起算 | 说明 |
|---|---|---|---|
| 严蔚敏等（国内多数本科） | 根第 1 层 | 与"层数"同义，根=1 | "深度"常被定义成"最大的层次"，于是 depth(根)=1 |
| CLRS / 国际通用 | 根第 1 层 | 根=0（边数） | $\mathrm{depth}=\mathrm{level}-1$ |
| 某些图形学/实现 | 根第 0 层 | 根=0 | 与数组下标一致 |

> 结论：**"层数第几层"几乎总是 1 起**（生活化）；**"深度"在算法书中多为 0 起**（数边）；个别教材深度 1 起（数点）。本知识库默认 depth 0 起、level 1 起。

## 5. 层序相关操作（链接）

- 按层访问 = **层序遍历（BFS）**，见 [traversal.md](traversal.md)。
- 层数决定深度优先的栈深、宽度决定队列大小：对完全二叉树的 n 个节点，BFS 队列最多 $\lceil n/2\rceil$。
- 树链剖分/倍增里"跳层"依赖 level 的单调性（见 [lca.md](lca.md)）。
