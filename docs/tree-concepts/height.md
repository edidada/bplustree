# 高度（Height）

## 1. 定义

- **节点 $v$ 的高度** $h(v)$：从 $v$ 到其子树内 **最远叶** 的 **最长向下路径上的边数**。
- 叶节点 $h=0$。
- **树的高度** = 根的高度 $h(\mathrm{root})$。
- **空树（NIL）的高度 = −1**，这是为了让"只有一个节点的树高度为 0"且"父高度 = 1 + max(子高度)"对空子节点也成立：

$$h(v) = 1 + \max\big(h(\mathrm{left}),\, h(\mathrm{right})\big),\qquad h(\mathrm{NIL})=-1$$

```
        (a) h=2
       /   \
   (b) h=1  (c) h=1
    /  \
(d) h=0 (e) h=0
树高 = h(a) = 2；h(d)=0（叶）
```

## 2. 关键性质

1. **树高 = 最大深度**（数值相等）：根到最远叶的那条路径既是"最深点"，也定义根的高度。
   $$h(\mathrm{root}) = \max_{v} \mathrm{depth}(v)$$
   但注意**单点的高度与深度无关**：右图 $b$ 的深度 1、高度 1；$d$ 深度 2、高度 0——不要混。
2. **空树 −1 约定的意义**：直接支持归纳式 $h(v)=1+\max(h(\text{子}))$，且使"含 $n$ 个节点的树高 $\ge \lceil \log_2(n+1)\rceil-1$、$\le n-1$"等公式整洁。
3. **最小高度 / 平衡判据**：二叉树含 $n$ 节点高度至少 $\lfloor \log_2 n\rfloor$；"高度平衡"即要求所有节点的左右子树高度差受限 → [avl-tree.md](avl-tree.md)。
4. **黑高 / 秩**：红黑树用"黑高"（到空叶的黑节点数，NIL 视为黑、高度当 0）作平衡不变量，是空树 −1 约定的直接推广 → [red-black-tree.md](red-black-tree.md)。

## 3. 教材起算差异对照

| 定义 | 叶高 | 空树高 | 采用 |
|---|---|---|---|
| 本库默认：边数 | 0 | −1 | CLRS、Knuth |
| 严蔚敏等国内：层数 | 1 | 0（空树高为 0） | 节点数计数 |
| 部分教材 | 1 | 0 | 把"叶在第 1 层"推广 |

> 国内教材（严蔚敏《数据结构》）通常把高度定义成"层次数"：叶高为 1、空树为 0；CLRS 系数"边"。二者在"空树"与"叶"上各差 1。做算法题/读论文时按 CLRS 系即可；考试读国内教材要按该校约定。

## 4. 各层级视角

- **本科**：递归求高、判断平衡、树高下界（$\ge \lfloor\log_2 n\rfloor$）、计算完全二叉树的高度。
- **硕士**：所有"平衡树"的本质都是给高度加约束并把维护摊到每次操作上：
  | 结构 | 高度约束 | 维护代价 |
  |---|---|---|
  | AVL | 左右子树高差 ≤ 1 | 旋转 $O(\log n)$，插入后至多 2 次旋转 |
  | 红黑树 | 黑高平衡 + 红规则 ⇒ 高 ≤ 2·黑高 | 变色/旋转 $O(\log n)$ |
  | B 树 | 所有叶同深 ⇒ 高度 $O(\log_m n)$ | 分裂/合并 |
  | splay | 无显式约束（摊还） | 每次访问旋转 |
- **博士/研究**：树的**高度分布**是随机结构理论的核心（随机 BST 期望高 $O(\log n)$、方差 $O(\log\log n)$）；双端队列/动态树的势能分析也常以"潜在高度"定义势函数。

## 5. 算法中"求高度"注意

```c
int height(struct node *root) {        /* 默认：空=-1，叶=0 */
    if (!root) return -1;
    int l = height(root->left), r = height(root->right);
    return (l > r ? l : r) + 1;
}
```
- 递归中反复调用是 $O(n^2)$ 隐患（AVL 判定要同时返回高与是否平衡或后序一次性算）。
- 工程上常把 height 存进节点/线段树叶子（如 B+ 树节点高度在层序实现中隐式）。
