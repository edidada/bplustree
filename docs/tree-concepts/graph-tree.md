# 自由树 / 图论中的树（Free Tree）

## 1. 定义

无向图 $G=(V,E)$ 是（自由）树，若它 **连通且无环（acyclic & connected）**。它**没有指定根**，也不存在"父/子"——根树是自由树 + 选根定向。

> 对照 [tree.md](tree.md)：数据结构教材先讲"有根树"，图论教材先讲"自由树"。二者关系：
> 自由树任取一点作根，按唯一路径定向，即得一棵**有根树**；反过来有根树忽略方向就是自由树。

## 2. 树的充要条件（六个等价命题，图论核心）

设 $n=|V|,\ m=|E|$，以下等价（每条都常被当"树"的另一种定义使用）：
1. 连通且无环；
2. 连通且 $m=n-1$；
3. 无环且 $m=n-1$；
4. 任意两顶点间**恰有一条简单路径**；
5. 连通，但删任意一条边即不连通（**边极小连通**）；
6. 无环，但加任意一条边恰产生一个环（**边极大无环**）。

**推论工具**：
- 判断连通：从某点 DFS 得 $n-1$ 条边且无环；
- 加一条边产生环 $\Leftrightarrow$ 两端已在同一棵树 → 并查集判环（[union-find.md](union-find.md)）与 [spanning-tree.md](spanning-tree.md) 直接使用命题 6/2。

## 3. 树作为"最稀疏的连通图"

- $m=n-1$ 是最小连通边数：更少必不连通，更多必有环；
- 树的平均度 $\bar d = 2m/n = 2-2/n < 2$ → 树必含**度 ≤1** 的点（叶），这个"有叶引理"是所有树归纳证明的基础；
- 树是**二分图**（可黑白染色无奇数环）。

## 5. 无根树 → 有根化的工程处理

算法里通常把无根树以某点 DFS 得到**父子关系 + 时间戳**：
- 任意点为根 → 变成根树，从而套用子树/深度/LCA 全部工具（[lca.md](lca.md)）；
- 换根技巧（rerooting）：二次 DFS 计算"以每个点为根"的答案（换根 DP），竞赛/研究常用。

## 6. 教学层级

- **本科（离散数学/图论初步）**：六个等价条件、$m=n-1$、树的应用（网络、Huffman、生成树）；
- **硕士算法**：树是无环最短路问题的特例（任意树 DFS 即得所有最短路）；树的直径/重心/DP 专题；
- **博士/组合**：树计数（Cayley [prufer-sequence.md](prufer-sequence.md)）、随机树、树的谱（Laplacian 特征值）等。
