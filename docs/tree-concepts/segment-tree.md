# 线段树（Segment Tree）

## 1. 定义

**线段树**是一种把一维区间"**二分递归划分**"的**平衡二叉树**：每个节点代表一个区间 $[l,r]$，其左右子树代表 $[l,mid]$ 与 $[mid{+}1,r]$（$mid=\lfloor(l{+}r)/2\rfloor$），叶为单点。节点可存储该区间的**聚合信息**（和/最值/异或等，须满足**可结合**）。

```
区间 [1,8]，存区间和
               [1,8]:36
            /          \
      [1,4]:10        [5,8]:26
       /     \         /     \
   [1,2]:3  [3,4]:7 [5,6]:11 [7,8]:15
    /  \     /  \    /  \     /  \
   1    2   3    4  5    6   7    8
```

## 2. 复杂度（为什么是 $O(\log n)$）

- 规模 $n$ 的节点总数 $\le 4n$（可用 4 倍数组实现，或用 2 的幂扩展为完美树）；
- **区间查询** $[L,R]$：从根递归，节点区间完全在查询内→直接取聚合；否则下到子区间——任意区间**分解成 $O(\log n)$ 个规范节点**（至多 2 个/层）；
- **单点修改**：沿叶到根更新 $O(\log n)$ 个节点；
- **区间修改**：结合 **懒标记（lazy propagation）**，把"整段更新"打在节点上不下推，访问到时再下推 → $O(\log n)$。

```c
/* 区间和 + 区间加(懒标记) 的关键：更新与查询都只访问 O(log n) 个规范节点 */
void range_add(int o, int l, int r, int ql, int qr, long v) {
    if (ql <= l && r <= qr) { tag[o] += v; sum[o] += v * (r - l + 1); return; }
    push_down(o, l, r);
    int mid = (l + r) >> 1;
    if (ql <= mid) range_add(o<<1, l, mid, ql, qr, v);
    if (qr >  mid) range_add(o<<1|1, mid+1, r, ql, qr, v);
    sum[o] = sum[o<<1] + sum[o<<1|1];
}
```

## 3. 与相关"区间树"家族区分（硕士高频混点）

| 结构 | 形态 | 典型问题 |
|---|---|---|
| **线段树（segment tree）** | 固定区间二分的平衡树 | 区间求和/最值/加、最大子段和、扫描线（矩形面积并） |
| 树状数组 BIT | 按**二进制低位**分块的前缀结构 | 前缀和 + 单点改；码最短 |[fenwick-tree.md](fenwick-tree.md) |
| 区间树（interval tree） | **以区间为元素**的 BST（按中点为枢） | 求与给定区间相交的所有区间 |
| 平衡 BST（[bst.md](bst.md)） | 键有序 | 动态集合（可加子树信息做序统计/区间聚合） |
| 动态开点线段树 | 稀疏区间按需建 | 值域大/可持久化 |

## 4. 变体（研究生/竞赛方向）

- **可持久化线段树（主席树）**：每次修改只复制路径 $O(\log n)$ 节点、共享其余——静态区间第 k 大。
- **线段树合并 / 分裂**：值域线段树合并处理树上众数/可并集合。
- **zkw 线段树**：用堆式下标、非递归、快。
- **动态开点**：值域 $10^9$ 不建满。
- **扫描线**：把矩形问题转成"y 轴线段树维护覆盖长度"。

## 5. 什么时候用它 vs 树状数组

- BIT 能做"可逆聚合 + 前缀可表达"（和、异或）的**单点改 + 前缀查**：码短、常数小、空间省；
- 线段树能处理：区间改（懒标记）、不可逆聚合（最值无"减"）、需要组合更复杂的信息（矩阵、最大子段）→ 用线段树。
- 两者都是把 [traversal.md](traversal.md) 的"区间化思想"建立在**完全二叉树的顺序编号**上（父 `i/2`、子 `2i,2i+1`，见 [binary-heap.md](binary-heap.md)）。

## 6. 教学层级

- **本科/竞赛入门**：单点改区间查的线段树与 BIT；
- **硕士算法课**：懒标记、可持久化、与区间树/扫描线的联系；
- **博士/高级**：线段树的结构即"分治 + 索引"模板，还可套上随机化（treap 可持久化线段树?）等组合。
