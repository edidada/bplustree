# 树术语总汇（根 / 叶 / 内部节点 / 父 / 子 / 兄弟 / 祖先 / 后代 / 子树）

> 本文集中定义树中"亲属/结构"术语。配图全库通用：

```
               (a)  ← 根 root（无父）
              /   \
           (b)    (c)
          /   \      \
        (d)   (e)    (f)
              /
            (g)
```

## 1. 单个节点角色

| 术语 | 英文 | 定义 |
|---|---|---|
| **根** | root | 唯一没有父节点的节点。非空树恰有一个根 |
| **叶 / 终端节点** | leaf / external node / terminal node | 没有子节点的节点（度为 0），上图中 $d,e,f,g$ |
| **内部节点** | internal node / branch node / non-leaf | 至少有一个子节点的节点，上图中 $a,b,c$。树仅一个节点时它是根同时是叶 |
| **孤儿** | — | 非正式说法，指无父节点者（即根）；一般不用 |
| 虚根/哑节点 | dummy/sentinel | 为统一算法人为加的父节点（如二叉树空指针统一成 NIL） |

> 注意术语歧义：CLRS 用 **external node** 指"叶"或"NIL 空叶"；而在"扩充二叉树"语境下 external 指新增的空叶、internal 指原节点（见 [binary-tree-forms.md](binary-tree-forms.md) 中的扩展二叉树）。

## 2. 父子与兄弟

| 术语 | 英文 | 定义 |
|---|---|---|
| **父 / 双亲** | parent | 直接上层节点；$b$ 的父是 $a$。根无父 |
| **子 / 孩子** | child | 直接下层节点；$a$ 的子为 $b,c$。一个节点的子构成有序/无序集合（见 [ordered-tree.md](ordered-tree.md)） |
| **兄弟** | sibling | 父节点相同的两个节点互称兄弟；$d,e$ 是兄弟，$b,c$ 也是兄弟 |
| **堂兄弟** | cousin | 父节点是兄弟关系（在同一层但不同父）的节点（本科讲义常用，工程中少用） |

## 3. 祖先 / 后代

| 术语 | 英文 | 严格/不严格 |
|---|---|---|
| **祖先** | ancestor | 从根到该节点路径上的节点。**严格祖先** 不含自身；教材常含混，本库采用：祖先 = 路径上的节点（含根、不含自身），"自身的祖先含自己"的版本会标注"非严格" |
| **后代 / 子孙** | descendant | 该节点子树内的所有节点。**严格后代** 不含自身 |
| **子孙** | descendant | 同后代，多用于族谱隐喻 |

深度关系（见 [depth.md](depth.md)）：
- 祖先/后代关系 $\Leftrightarrow$ $u$ 在根到 $v$ 的路径上（$u$ 是 $v$ 的祖先）$\Leftrightarrow$ $v$ 在 $u$ 的子树中（$v$ 是 $u$ 的后代）。
- 树的高度/层数与祖先链长度直接相关。

## 4. 子树

节点 $v$ 的 **子树（subtree）** = 以 $v$ 为根的那棵递归子树：$v$ 本身 + $v$ 的全部（严格）后代，保留原有边。
- 上图中 $c$ 的子树为 $\{c,f\}$；$b$ 的子树为 $\{b,d,e,g\}$。
- 空树没有子树；叶的子树是它自身（或视为单节点树）。
- **子树在算法上的作用**：几乎一切树问题都先问"这个操作只影响哪棵子树"，平衡旋转、分裂合并、区间统计全部以子树为单位。

## 5. 路径与分支术语

| 术语 | 含义 |
|---|---|
| 从根到 $v$ 的路径 | 唯一祖先链 |
| 树的高度 / 最深深度 | 根到最远叶的边数（见 [height.md](height.md)/[depth.md](depth.md)） |
| 分支节点 | = 内部节点，含子者 |
| 单分支/双分支节点 | 二叉树中有一棵/两棵子树者（某些教材在"线索树/三叉链"讨论中用于统计空链域） |

## 6. 全库术语速查差异提醒

- "祖先是否含自身"、"层数从 0 还是 1"各教材不一致 → 以各篇「约定」节为准。
- **parent 记为 $\mathrm{pa}(v)$**、子集记为 $\mathrm{ch}(v)$ 是论文/讲义常见记号。
- 竞赛/工程中还常用：父亲数组 `fa[]`、儿子列表 `children[]`、以及"重儿子"（子树最大的儿子，见 [lca.md](lca.md) 树链剖分）。
