# R 树（R-Tree，空间对象索引）

## 1. 定义

**R 树**是**平衡的多路搜索树**（B 树的"空间版"，见 [b-tree.md](b-tree.md)），用于索引**二维及以上空间对象**（点、线、面、包围盒）：

- 每个节点 = 一个磁盘页，存储若干 **MBR（最小包围矩形 minimal bounding rectangle）** 条目；
- **叶条目**：空间对象 + 其精确几何/指针；
- **内部条目**：子节点的 MBR + 子指针；**父 MBR 必须包含全部子 MBR**（不变量）；
- 同一深度的全部叶（无叶链亦可，但叶间可用指针加速顺序遍历）。

```
                    [ 根 MBR 覆盖全部 ]
                   /        \
         [子1 MBR]          [子2 MBR]
        /    |    \          /    |    \
      a     b     c        d     e     f     ← 空间对象(叶)
（叶条目不重叠在数据结构上不要求；父盒覆盖子盒是硬约束）
```
- **查找/范围**：从根起，若查询区与节点某条目 MBR 相交则进入其子树 → 剪枝大多数子树；
- **高度 $O(\log n)$**（页式多路），磁盘 I/O 与 B 树同级。

## 2. 插入/分裂（核心难点：最小化重叠）

插入从根下行到能"装下对象且扩张最少"的叶；**叶满则分裂**：
- 分裂成两组，使两组 MBR 总面积/重叠最小——最优是 NP 的，用启发式（如 quadratic/linear split）；
- 分裂向上传播（同 B 树）；父满则再分裂，根分裂树长高。

删除：找条目所在叶删除；节点下溢（< 半满）则**重插入**其条目（而非与兄弟合并）——Guttman 原版策略。

## 3. 为什么是"空间对象的 B 树"

| 对照 B 树 | R 树 |
|---|---|
| 键有序、节点=块 | 条目是无"总序"的空间盒 |
| 分裂取中位键 | 分裂=最小化 MBR 重叠的启发式 |
| 数据在叶（B+） | 数据/指针在叶 |
| 高度 $O(\log n)$ | 同 |
| — | 新增：**MBR 是查询剪枝的依据** |

## 4. 变体家族（按字母记）

| 变体 | 改进 |
|---|---|
| **R\* 树** | 插入选择更精细：最小化重叠/面积/周长、强制重插入（forced reinsertion）→ 查询质量大幅提升，工程最常用 |
| R+ 树 | 兄弟 MBR 不重叠（牺牲覆盖换查询清晰），空间复用差 |
| Hilbert R 树 | 按 Hilbert 曲线序分页 → 顺序友好、静态构建好 |
| 空间填充曲线 + B+ | 把 2D 映射 1D 后用 B+ 树（PostGIS/GIS 常见实践） |
| k-d-B 树 | KD + B 的组合（对象切分，见 [kd-tree.md](kd-tree.md)） |

## 5. 复杂度与取舍

- 构建 $O(n\log n)$；点/区域查询平均好、最坏差（重度重叠时退化）；
- 权衡轴：**重叠最小化**（查询快）vs **节点占用**（空间利用高）vs **插入简单**；
- 空间对象大（复杂多边形）常用**多层过滤**：先 R 树粗筛 MBR → 再精确几何求交（两步过滤思想在空间索引里普适）。

## 6. 应用与教材

- 应用：GIS（PostGIS/空间数据库）、地图服务、游戏碰撞、CAD、多维索引库（如 SQLite R\*Tree 模块!）、数据库空间扩展；
- 教材：数据库系统（空间索引章节，硕）、计算几何导论；原始论文：Guttman 1984。
- SQLite 自带 `rtree` 模块使用 R\*Tree——与本仓库读同一家族的"页式多路平衡"但维度不同（见 [b-tree.md](b-tree.md) 讨论的 SQLite btree）。
