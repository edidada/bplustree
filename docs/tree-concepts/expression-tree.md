# 表达式树（Expression Tree）

## 1. 定义

**表达式树**是表示算术/逻辑表达式的**二叉树**：

- **叶节点** = 操作数（常量/变量）；
- **内部节点** = 运算符（单目/双目/多目）；
- 左右子树分别表示运算符的左右操作数子表达式。

```
中缀:  (a + b) * (c - d)

          (*)
         /   \
       (+)   (-)
      /   \ /   \
     a    b c    d
```

## 2. 三种遍历 = 三种表达式（最核心结论）

| 遍历 | 得到 | 例（上面树） |
|---|---|---|
| 中序 | **中缀式**（括号版需自行加括号） | `(a+b)*(c-d)` |
| 前序 | **前缀式 / 波兰式** | `* + a b - c d` |
| 后序 | **后缀式 / 逆波兰式（RPN）** | `a b + c d - *` |

- 前缀/后缀式**不需要括号**：运算符顺序固定，栈求值即可。
- 中缀式要还原优先级必须括号（或不含括号的化简），因此编译器通常**不直接用中序输出**而是构建语法树。
- **后缀表达式求值** = 表达式树的后序遍历（遇操作数压栈、遇运算符弹两数运算再压栈）。

## 3. 构建表达式树

1. **后缀式 → 树**：扫描，操作数建叶入栈；运算符弹出栈顶两个子树作为右/左子（**注意出栈顺序**：先弹出的是右操作数），合成新子树入栈。
2. **括号中缀 → 树**：用递归下降/调度场算法（shunting-yard）先转后缀再建树，或直接按运算符优先级递归切分。
3. 一般**从中缀中序 + 括号结构**出发，递归：在最低优先级处切根。

```
后缀 a b + c d - *
  遇a→(a)  遇b→(b)  遇+ → 弹出(b)作右子、(a)作左子 → 压入(+)  ...
  …… 最终根为 (*)
```

## 4. 表达式树的性质

- 表达式树的**前/后序形态对运算符的结合性/优先级有约束**：同一运算符优先级的结合性通过树形体现。
- **严格二叉树**：双目运算符下所有内部节点度为 2 → $n_0=n_2+1$（[binary-tree-forms.md](binary-tree-forms.md)）。
- **树同构判定**：两个数学表达式是否"结构一致"可归约到树的同构（[tree-isomorphism.md](tree-isomorphism.md)）；常量折叠、公共子表达式提取都是**子树等价**问题。
- **不同但等价的树**：如 $a\times(b+c)$ 与 $a\times b + a\times c$ 是不同树。

## 5. 工程与理论意义

- **编译器/解释器**：语法分析树（parse tree）是表达式树的一般化；表达式树只关心运算，是 AST 的教学简化版。
- **后缀（RPN）**：栈机、JVM/CLR 字节码的求值模型。
- **推导树（derivation tree）**：形式文法 $E\to E+E\mid E*E\mid (E)\mid\text{id}$ 的每棵分析树即一表达式树——树结构 = 文法结构（博士/形式语言视角，与 [trie.md](trie.md) 的"自动机树"同为语法树思想）。
- **DAG 优化**：合并相同子树后表达式树变 DAG，是编译器公共子表达式消除的核心。
