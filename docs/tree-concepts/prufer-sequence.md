# Prufer 序列（Prüfer Sequence）与 Cayley 定理

## 1. 核心思想

**Prüfer 序列**给出无根树（顶点标号 $1..n$）与长为 $n-2$ 的序列之间的**一一对应**，从而把"数树"变成"数列"。

## 2. 树 → Prüfer 序列（编码）

重复直到剩两个顶点：
1. 取当前树上**编号最小的叶**；
2. 输出它的**唯一邻居**编号；
3. 删去该叶。

```
树： 1-3-2-4 且 5 连 4  （示意）  n=5
最小叶 1，邻居 3 → 序列首 3，删 1
剩叶：2(邻3)? 2 的邻居 3 但 2 还连着 3-4 … 逐步：
示例输出序列 (3,4,3)：长度 n-2=3
```
- 每次删除一个叶，做 $n-2$ 次后剩两顶点结束；
- 该序列**唯一**；不同树 ⇒ 不同序列。

## 3. 序列 → 树（解码）

已知度数：顶点 $v$ 在序列中出现次数 = $\deg(v)-1$。
1. 统计各点出现次数（叶=出现 0 次）；
2. 重复：取"未在序列中出现、编号最小"的叶 $u$，取序列首元素 $w$，连边 $(u,w)$；删 $u$ 与序列首；
3. 最后把剩的两个顶点连边。

## 4. 推论：Cayley 公式（最重要的数树结果）

- 树上每个顶点出现次数可任意组合 → $n$ 个标号顶点的**无根树数**：
$$\boxed{\,T(n) = n^{\,n-2}\,}$$
- 推论 1：$n$ 个标号顶点的**有根树**数 $= n\cdot n^{n-2} = n^{n-1}$（每棵树有 $n$ 种选根法）；
- 推论 2：**生成树计数**：完全图 $K_n$ 恰有 $n^{n-2}$ 棵生成树（[spanning-tree.md](spanning-tree.md)）；
- 一般化：任意连通图的生成树数可由 **Kirchhoff 矩阵树定理**（Laplacian 的任意主子式行列式）给出；Prüfer 是 $K_n$ 情形的纯组合证明。

## 5. 应用

- **随机树生成**：随机 $n-2$ 长序列 → 均匀随机树（用于随机图/算法实验）；
- 判断/构造树性质：用度序列恢复树、验证某些"树的存在性"；
- 树的**编码长度**：$O(n\log n)$ 位（每个编号 $\log n$），是"树的可压缩表示"下限讨论起点（博士方向：succinct tree 与 Prüfer 的关系）。

## 6. 教学层级

- **本科/组合数学**：会手工编码解码、会证 Cayley（Prüfer 双射证法）；
- **硕士图论/算法**：生成树计数、随机树；
- **博士**：随机树度量（高度/直径分布）常从 Prüfer 的"度数分布"入手。

## 7. 易错点

- 序列元素范围 $1..n$、长度固定 $n-2$（$n=1,2$ 时退化为空序列，约定树数 1）；
- 解码时"最小**叶**"而非"最小编号顶点"（叶=度数 1）；工程实现维护一个最小叶堆（O(n log n) 或线性指针）。
