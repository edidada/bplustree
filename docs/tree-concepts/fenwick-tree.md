# 树状数组（Binary Indexed Tree, Fenwick Tree / BIT）

## 1. 定义与直觉

**树状数组**用**一个数组**维护原数组 $a[1..n]$，支持 $O(\log n)$ 的**前缀和查询**与**单点修改**。它并不是显式建树，而是通过下标二进制**最低位 1（lowbit）**定义隐含的"树"关系：

$$ \mathrm{lowbit}(i) = i \,\&\, (-i) $$

$c[i]$ 维护区间 $[\,i-\mathrm{lowbit}(i)+1,\ i\,]$ 的聚合（如和）：

```
c[i] 覆盖"以 i 结尾、长度 lowbit(i)"的区间
示例 i=6 (110): lowbit=2 → c[6] 覆盖 a[5..6]
     i=8 (1000): lowbit=8 → c[8] 覆盖 a[1..8]

           c[8]=a[1..8]
        /       \
    c[4]=a[1..4] c[?]
  ...
从 1 累加查询前缀：i 依次减去 lowbit(i)
修改 a[i] 影响：i 依次加上 lowbit(i)
```

## 2. 两个核心操作

```c
void add(int i, int delta) {                 /* 单点加 delta */
    for (; i <= n; i += i & (-i)) c[i] += delta;
}
long prefix_sum(int i) {                     /* a[1..i] 的和 */
    long s = 0;
    for (; i > 0; i -= i & (-i)) s += c[i];
    return s;
}
```
- 单点改：从 $i$ 向上跳 $\le \log n$ 次；
- 前缀查：从 $i$ 向下跳 $\le \log n$ 次；
- 区间和 = `prefix(r) − prefix(l−1)`；
- **kth（找第 k 小）**：配合二分/倍增沿 lowbit 树跳，$O(\log n)$。

## 3. 为什么叫"树"：结构解释

如果把 $i$ 的父定义为 $i+\mathrm{lowbit}(i)$、把 $c[i]$ 看成节点，则恰好构成一棵**森林/隐式完全树**（覆盖关系形成包含序）——它是"以二进制划分前缀"的隐式平衡树：

- 复杂度由"二进制位数 $=\log_2 n$"决定；
- 与线段树（[segment-tree.md](segment-tree.md)）完全二叉树的二分不同：BIT 按 **lowbit 分块**，因此代码极短、常数小、空间 $n+1$；
- 直觉上 BIT ≈ "**每个前缀都拆成 O(log n) 个不相交块**"，块的区间右端点决定了它的树位置。

## 4. 适用范围与限制

| 能力 | 说明 |
|---|---|
| 单点改 + 前缀查 | 标准 |
| 区间加 + 区间和 | 用两个 BIT（差分树 $d$ 与 $i\cdot d$）实现 |
| 二维 BIT / 高维 | 每维套 BIT，$O(\log^k n)$ |
| 逆序对/顺序统计 | 值域离散化 + 单点计数前缀和 |
| **不可逆聚合**（max 等无"减"） | 前缀 max 可做；区间任意 max 需线段树 |
| 区间最值 + 区间修改 | 不适合 → 用线段树 |

## 5. 与线段树的定位总结

- **BIT**：只支持"前缀可逆"（和/异或）与单点改；快、省、实现 5 行。
- **线段树**：更通用（区间改、不可逆聚合、复杂合并信息）；代码 30–100 行。
- 工程建议：能 BIT 就不线段树；需要懒标记/最值/区间改则线段树。
- 两者都依赖完全二叉树的顺序存储与 $O(\log n)$ 跳层，见 [binary-tree-forms.md](binary-tree-forms.md)。

## 6. 历史与教材

- Peter Fenwick 1994 提出（另称 BIT，90 年代前有类似结构）；中文教材常列入"树状数组"于提高章节；
- 本科/竞赛算法基础；硕士用于与线段树对照、理解"低位的树"（lowbit 树形 = 树上到根的 O(log n) 跳）；
- 树上 BIT 扩展：用 dfs 序把子树变成区间，配合 BIT 做子树加/子树和 → [lca.md](lca.md) 中"子树区间化"思想的实例。
